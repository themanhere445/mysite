# planering!
Jag ska göra ett enkelt spel där spelaren styr en fyrkant och ska undvika fiender som faller från toppen av skärmen.

Det ska finnas:
- En spelare som kan röra sig höger och vänster
- Fiender som faller ner
- Kollision mellan spelare och fiender
- Poängsystem
- Game over

Jag kommer använda variabler, loopar och if-satser för att få spelet att fungera.
